## 📋 Descripción del Proyecto
Este repositorio contiene un Análisis Exploratorio de Datos (EDA) aplicado al conjunto de datos público [*Students Performance in Exams*](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams) disponible en Kaggle. El objetivo principal es identificar qué factores socioeducativos (curso de preparación, tipo de almuerzo, nivel educativo de los padres, género y grupo) se asocian con un mayor puntaje promedio en los estudiantes.

## 📊 Pregunta de Investigación
> **¿Qué factores se asocian con un mayor puntaje promedio de los estudiantes, y qué tan fuerte es cada asociación?**
